 ChitChat 💬

ChitChat is a sleek, real-time chat application where users can connect, send messages, and stay in touch—effortlessly.

✨ Features

- 🔐 **User Authentication** – Sign up and log in securely
- 💬 **Real-Time Messaging** – Powered by Socket.io for instant communication
- 📱 **Responsive Design** – Optimized for mobile and desktop
- 🟢 **Online/Offline Status** – See who's active in real time
- 📸 **Media & File Sharing** – (Optional, if implemented)
- 🎨 **Polished UI** – Clean, modern interface with animated transitions

## 🛠️ Tech Stack

| Layer       | Technology                      |
|------------|----------------------------------|
| Frontend| React / Next.js                 |
| Styling | TailwindCSS + Lottie animations |
| Backend  | Neon (PostgreSQL)               |
| Database | PostgreSQL                      |                     |
| Icons  | Tabler Icons / React Icons      |
| Animations| Lottie-React                   |
